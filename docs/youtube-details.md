# YouTube details for the Cartwalk demo

**Title**

Cartwalk: can an AI agent buy from your store? (KaneCLI Online Hackathon)

**Description**

Cartwalk tests a store the way an AI shopping agent would use it. A Kane CLI shopper walks the store in a real Chrome and never pays, plain code decides four checks (reached checkout, step budget, price math, shipping promise), a coding agent (Claude Code) fixes what fails, and Kane walks again to prove the fix. Every step goes into a hash-chained log you can verify in your browser.

Built for the KaneCLI Online Hackathon by TestMu AI.

Site and setup guide: https://ibnweb3.github.io/cartwalk/
Code: https://github.com/ibnweb3/cartwalk
Try it: npx github:ibnweb3/cartwalk help

Honest limits: two outside stores walked, once each (Saleor passed; Kane confirmed a 500 on add to cart on Medusa's public demo, which may be that demo's backend). Windows 11 only so far. The opening graphic is an illustration, not a recording.

**Settings:** Audience = No, it's not made for kids. Visibility = Unlisted (judges open it by link) or Public.
